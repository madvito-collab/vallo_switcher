# Проверка MVP для Windows

Что проверить автору на своём компе после установки первой виндовой сборки (первая очередь: переключение раскладки). Отмечай галочки и пиши, что не так: в каком приложении, что набрал, что получилось.

## Установка

1. На странице сборки в GitHub Actions скачай артефакт `ValloSwitcher-win-x64` (zip).
2. Правой кнопкой по zip → «Свойства» → внизу «Разблокировать» → OK.
3. Распакуй **всю** папку (не запускай exe прямо из архива: рядом должна лежать папка `Data`).
4. Закрой Punto Switcher, Caramba и другие переключатели, если есть.
5. Запусти `ValloSwitcher.exe`. SmartScreen: «Подробнее» → «Выполнить в любом случае». Если Защитник ругается — «Защита от вирусов и угроз» → «Журнал защиты» → «Разрешить».
6. В трее появится «ё» (если не видно — стрелка ^ справа внизу). Свитчер сам добавится в автозапуск.

## Основное

- [ ] Блокнот, Телега, браузер, Фигма: `ghbdtn ` → «привет », `,eltn ` → «будет ».
- [ ] Двойной левый Shift сразу после исправления — откат; тот же откат второй раз — слово запоминается и больше не исправляется.
- [ ] Двойной левый Shift после набора без исправления — переводит набранное.
- [ ] Быстрый набор длинного текста — буквы не пропадают и не переставляются.
- [ ] Меню по «ё»: «Автопереключение» снимается и ставится, «Завершить» закрывает свитчер и убирает значок.
- [ ] Светлая/тёмная тема панели задач — «ё» перекрашивается.
- [ ] Набор сразу после ручной смены раскладки (Alt+Shift / Win+Пробел) — ничего лишнего не исправляется, первые буквы не теряются.
- [ ] С включённым Caps Lock: `GHBDTN` остаётся как есть (как на Маке — заглавные считаются аббревиатурой).
- [ ] Третья раскладка (если есть, например украинская) — свитчер молчит.

## Пароли

- [ ] Полностью закрой браузер, открой, зайди на страницу входа, сразу кликни в поле пароля и набери пароль «не в той» раскладке — ничего не переключается и не переводится.

## Игры и полный экран

- [ ] Игра на весь экран (или «оконный без рамки») — свитчер молчит, WASD не трогает.
- [ ] Майнкрафт в окне — двойной Shift (присесть) ничего не делает, чат не исправляется.
- [ ] Видео на весь экран (F11) — молчит.
- [ ] Включи «Автоматически скрывать панель задач», разверни Телегу и Фигму на весь экран — свитчер в них работает.

## Выделение

- [ ] Выдели `ghbdtn`, двойной левый Shift → «привет»; то, что было в буфере обмена до этого, через секунду снова в буфере. Проверь в Фигме и Телеге тоже: вставляется исправленное, а не старое содержимое буфера.
- [ ] Выдели `123` → двойной Shift: ничего не меняется, буфер прежний.
- [ ] В буфере большая картинка (скриншот), потом перевод выделения — картинка после этого снова в буфере.
- [ ] Excel: выбрана ячейка (не редактируется), двойной Shift — ничего не вставляется, буфер прежний.
- [ ] Терминал и VS Code: автопереключения нет, двойной Shift переводит только что набранное.

## Надёжность

- [ ] Сон → пробуждение → `ghbdtn ` исправляется.
- [ ] Win+L → разблокировать → набор работает, Shift/Ctrl не «залипли».
- [ ] Переименуй папку `Data` рядом с exe и запусти — в меню серым «Свитчер не запущен: нет папки Data — распакуйте архив целиком». Верни `Data`.
