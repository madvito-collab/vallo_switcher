# Проверка MVP для Windows

Что проверить автору на своём компе после установки первой виндовой сборки (первая очередь: переключение раскладки). Отмечай галочки и пиши, что не так: в каком приложении, что набрал, что получилось.

## Установка

1. На странице сборки в GitHub Actions скачай артефакт `ValloSwitcher-win-x64` (zip).
2. Правой кнопкой по zip → «Свойства» → внизу «Разблокировать» → OK.
3. Распакуй **всю** папку (не запускай exe прямо из архива: рядом должна лежать папка `Data`).
4. Закрой Punto Switcher, Caramba и другие переключатели, если есть.
5. Запусти `ValloSwitcher.exe`. SmartScreen: «Подробнее» → «Выполнить в любом случае». Если Защитник ругается — «Защита от вирусов и угроз» → «Журнал защиты» → «Разрешить».
6. В трее появится «ё» (если не видно — стрелка ^ справа внизу). Свитчер сам добавится в автозапуск.

## Основное

- [x] Блокнот, Телега, браузер, Фигма: `ghbdtn ` → «привет », `,eltn ` → «будет ».
- [x] Двойной левый Shift сразу после исправления — откат; тот же откат второй раз — слово запоминается и больше не исправляется.
- [x] Двойной левый Shift после набора без исправления — переводит набранное.
- [x] Быстрый набор длинного текста — буквы не пропадают и не переставляются.
- [x] Меню по «ё»: «Автопереключение» снимается и ставится, «Завершить» закрывает свитчер и убирает значок. 
- [x] Светлая/тёмная тема панели задач — «ё» перекрашивается.
- [x] Набор сразу после ручной смены раскладки (Alt+Shift / Win+Пробел) — ничего лишнего не исправляется, первые буквы не теряются.
- [x] С включённым Caps Lock: `GHBDTN` остаётся как есть (как на Маке — заглавные считаются аббревиатурой).
- [ ] Третья раскладка (если есть, например украинская) — свитчер молчит.

## Пароли

- [x] Полностью закрой браузер, открой, зайди на страницу входа, сразу кликни в поле пароля и набери пароль «не в той» раскладке — ничего не переключается и не переводится.

## Игры и полный экран

- [ ] Игра на весь экран (или «оконный без рамки») — свитчер молчит, WASD не трогает.
- [ ] Майнкрафт в окне — двойной Shift (присесть) ничего не делает, чат не исправляется.
- [ ] Видео на весь экран (F11) — молчит.
- [ ] Включи «Автоматически скрывать панель задач», разверни Телегу и Фигму на весь экран — свитчер в них работает.

## Выделение

- [x] Выдели `ghbdtn`, двойной левый Shift → «привет»; то, что было в буфере обмена до этого, через секунду снова в буфере. Проверь в Фигме и Телеге тоже: вставляется исправленное, а не старое содержимое буфера.
- [x] Выдели `123` → двойной Shift: ничего не меняется, буфер прежний.
- [x] В буфере большая картинка (скриншот), потом перевод выделения — картинка после этого снова в буфере.
- [x] Excel: выбрана ячейка (не редактируется), двойной Shift — ничего не вставляется, буфер прежний.
- [x] Терминал и VS Code: автопереключения нет, двойной Shift переводит только что набранное.

## Окно настроек

Та же страница, что на Маке, во встроенном Edge (WebView2). На Windows в ней только то, что есть: Основное, Раскладка, Справка, О программе.

- [x] Меню в трее → «Настройки…» — открывается окно как на Маке: слева меню, справа «Основное». Окно таскается за заголовок, тянется за края.
- [x] «Справка» и «О программе» в меню трея открывают окно сразу на этих страницах.
- [x] Переключи «Переключать автоматически» — галочка «Автопереключение» в меню трея тоже меняется, `ghbdtn ` больше не исправляется. Верни.
- [x] Сочетание → «Двойной правый Shift» — левый больше не переводит, правый переводит. Верни левый.
- [x] «Добавить приложение» → выбери любой exe (например, Блокнот) — он в списке, в Блокноте автопереключения нет. Убери корзиной.
- [x] «Не переключать слова» → добавь `ghbdtn` — в Блокноте `ghbdtn ` остаётся как есть. Убери корзиной — снова исправляется.
- [x] «Запускать вместе с системой» выключить → перезагрузиться: свитчер не стартовал. Запусти вручную и включи обратно.
- [ ] Тёмная тема Windows — окно тёмное; светлая — светлое. — **в тёмной теме шапка (где три кнопки управления окном ) светлая надо тоже делать тёмную в темной**
  - Поправлено: шапка ставится ещё раз, когда окно уже на экране, и перекрашивается при смене темы на ходу. Перепроверить: тёмная тема → шапка тёмная; не закрывая окно, переключить на светлую → шапка светлая.
- [x] Закрыл окно — свитчер работает дальше, значок в трее на месте.

## Установка и автообновление

Проверяется на выпуске `win-v0.1` из GitHub Releases (не на архиве из Actions).

- [ ] Удали распакованную папку старой версии (если в ней включён автозапуск — сначала выключи его в настройках).
- [ ] Скачай `ValloSwitcher-win-Setup.exe` со страницы выпуска, запусти. SmartScreen: «Подробнее» → «Выполнить в любом случае». Значок «ё» появился в трее, в меню «Пуск» есть Vallo Switcher.
- [ ] Меню в трее — есть «Проверить обновления…». Нажми: уведомление «Обновлений нет — у вас последняя версия 0.1».
- [ ] Настройки → О программе: «Версия 0.1», раздел «Обновления» с переключателем и «Проверено …».
- [ ] Перезагрузка — свитчер стартовал сам.
- [ ] Когда выйдет `win-v0.1.1` (выпустим для проверки): «Проверить обновления…» — уведомление «Обновление 0.1.1 готово», на «ё» красная точка, первой строкой меню «Перезапустить и обновить до 0.1.1». Клик по уведомлению или по строке — свитчер перезапустился, в «О программе» 0.1.1, точки нет.
- [ ] «Параметры → Приложения» — Vallo Switcher можно удалить, значок из трея пропадает.
