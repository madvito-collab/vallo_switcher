# Расстановка «ё» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** однозначные слова сами получают «ё» — на лету после границы слова и по двойному правому Shift; двойные (все/всё) не трогаются никогда.

**Architecture:** новый `Yoficator` в `ValloCore` (словарь «слово через е → слово через ё» из открытого `eyo-kernel`), подключается в конвейер на лету (`LiveTypographer.fixTypo`, после исправления опечатки) и в правый Shift (`KeyboardTap.typographySelection`, после `correctPhrase`). Свой переключатель в настройках, независимый от опечаток и типографики.

**Tech Stack:** Swift 6 / SwiftPM, swift-testing, macOS 14+; Python 3 для сборки словаря.

**Spec:** `docs/superpowers/specs/2026-10-30-yo-design.md`

## Global Constraints

- Двойные слова (`not_safe.txt`) не ставим никогда; «ё» → «е» не делаем никогда; слово, где «ё» уже есть, не трогаем.
- Отмена Backspace возвращает набранное и **не** кладёт слово в «Мои слова» (`undoneTypoWord` остаётся nil, если правка была только в «ё»).
- Регистр сохраняется: «Еще» → «Ещё», «ЕЩЕ» → «ЕЩЁ»; смешанный («еЩе») — не трогаем, как у опечаток.
- Переключатель «Расставлять «ё»», подпись «ещё, её, далёкий. Если слово может быть и с «е», и с «ё» (все/всё), не трогаем», по умолчанию включён, независим от опечаток и типографики; в исключениях `ContextGuard` не работает, как всё на лету.
- Словарь: `e2yo/eyo-kernel`, `dictionary/safe.txt`, MIT; лицензию кладём рядом со словарём и упоминаем в справке.
- Тексты интерфейса — на «вы», через `T(...)` (наша типографика).
- Git-команды (коммит, пуш) набирает ученик — исполнитель не коммитит, в конце даёт одну строку.

## Review Focus

1. Имена собственные (запись с заглавной, `Ёлкин`) применяются, только если набрано с заглавной: «елкин» строчными не трогаем. Тест в Task 1.
2. Слово из словаря, которое свитчер раскладки переключает посреди набора (как было с «вобщем») — тогда «ё» молча не ставится. Тест-конвейер в Task 3 по частым ё-словам.
3. Опечатка + «ё» в одном слове: «ещо» → опечатка не исправится (две правки), а «еше» → «еще» → «ещё». Тест в Task 2.
4. Отмена «ё» Backspace не учит «Мои слова», а отмена опечатки + «ё» — учит (была опечатка). Тест в Task 2.
5. Правый Shift по тексту с голосового ввода: «Да, еще все верно» → «Да, ещё все верно» («все» не трогаем). Тест в Task 1 (`fixPhrase`).
