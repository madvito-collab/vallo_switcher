# Vallo Switcher — опечатки и запятые

Дата: 2026-10-30
Статус: черновик на ревью
Основа: `2026-10-29-vallo-switcher-design.md`, `2026-10-30-typography-design.md` (версия 0.2 готова, метка `v0.2`)

## Зачем

Исправлять промахи пальцев и расставлять запятые, **не превращая живую речь в «литературный» текст**: сленг, жаргон, айтишные и дизайнерские слова, имена остаются как написаны. Автозамена macOS и телефонов бесит именно тем, что «ща» становится «час», а «фигма» — «фирмой».

## Что выяснил эксперимент (2026-10-30, 34 фразы + 148 промахов + 3000 редких слов)

- **Встроенная проверка macOS**: запятых не ставит; ломает айтишное («фигма» → «фирма», «пушнуть» → «пугнуть», «пулл реквест» → «пуля реквещт»). Не берём.
- **Qwen 2.5 1,5B** (модель-«болталка»): отвечает на текст вместо исправления («кинь ссылку» → «вот ссылка: google.com»), выдумывает, меняет смысл. Не берём.
- **SAGE (`ai-forever/sage-fredt5-distilled-95m`)**: хорошо ставит запятые и чинит опечатки, но ломает сленг («хз» → «хочу», «ща» → «сейчас», «спс» → «СП:»). 368 МБ, ~0,2 с на фразу. **Берём только для запятых, с фильтром.**
- **Свой исправлятор опечаток на словаре**: 82% промахов исправлено верно (лишняя буква 36/36, задвоение 24/25, перестановка 35/39, пропущенная 26/48), 1 ошибка на 148; из 3000 редких правильных слов испорчено 2 (и те — опечатки в самом словаре); контроль из 88 слов сленга и жаргона — 0 тронуто. 0 МБ, мгновенно. **Берём для опечаток.**

## Что входит

1. **Опечатки** — свой исправлятор, только промахи пальцев.
   - **Тихо, на лету** — на конце слова (пробел, знак, Enter/Tab). Галочка в настройках, **по умолчанию включено**.
   - **По сочетанию** — тот же двойной правый Shift, что у типографики, по выделенному тексту.
2. **Запятые** — необязательная скачиваемая модель, **только по сочетанию** (двойной правый Shift по выделенному тексту).
3. **Двойной правый Shift делает всё сразу**: опечатки → запятые (если модель скачана) → типографика.
4. **Мои слова** — слова, которые исправлятор и модель не трогают.

## Не входит

- Настоящие ошибки правописания («в течении», «извените», «-тся/-ться») — это грамматика, её делают только большие модели, и там же они ломают живую речь.
- Опечатки в английском тексте.
- Замена буквы на другую («фигма» → «фирма») — главный источник бесячих исправлений.
- Подсказки у курсора.
- Дообучение модели.

## Исправлятор опечаток (`ValloCore`)

Слово исправляется, **только если всё сразу**:
- слово из кириллицы, **не короче 5 букв**;
- его нет среди **20 000 частых слов**, оно не из разговорных словечек и не из «Моих слов»;
- среди частых слов есть вариант, отличающийся **одним промахом**:
  - лишняя буква или задвоение — кроме последней буквы (там окончание: «кейсы» → «кейс» — не опечатка);
  - пропущенная буква — кроме места прямо перед последней;
  - перестановка соседних букв — включая две последние («привте» → «привет»);
- вариант **один** или самый частый **в 10 раз частотнее** второго; сам вариант встречается в словаре не реже 200 раз;
- если слово есть в хвосте словаря (с 20 001 по 50 000 место — редкое, но настоящее), то только когда вариант **в 300 раз частотнее** («пожалуста» → «пожалуйста» — да; «планку» → «плану» — нет).

**Регистр не меняем никогда** (решение ученика): исправляется только опечатка, заглавные остаются там, где их поставил человек — «Првет» → «Привет», «ПРВЕТ» → «ПРИВЕТ», «првет» → «привет». Строчную на заглавную не меняем. Имена и названия защищены правилами «не короче 5 букв» и «вариант — частое слово»; перед сборкой правило проверяется на списке имён и брендов (тест «контроль»). Дефисы: «ктото» → «кто-то», «какой то» → «какой-то» (частицы -то, -нибудь, -либо, -таки) — тоже опечатка.

## Модель для запятых

- Модель **SAGE** (Сбер, открытая лицензия), ужатая до ~100–150 МБ. Запускается **внутри приложения без интернета**.
- **Скачивается в настройках** (вкладка «Опечатки»): название, размер, «Скачать» / «Удалить», полоса загрузки, статус «Активна». Без модели всё остальное работает, просто без запятых.
- Где лежит файл модели для скачивания — публичное место (отдельный публичный репозиторий релизов на GitHub или Hugging Face); выбирает ученик при ревью спеки.

**Фильтр поверх модели** — из её ответа берём только безопасное:
- **запятые и знаки** `, ? ! : ;` после слов — да; точку между цифрами («15. 00») — нет;
- **замену слова** — только если исправлятор опечаток тоже счёл бы его опечаткой (правила выше) **или** это замена «е» на «ё», дефис в «кто-то» / «какой-то»;
- **добавленные и удалённые слова** — никогда;
- **заглавную букву в начале и точку в конце** — только если включена галочка «Заглавная буква и точка» (по умолчанию выключено: в мессенджерах они не нужны).

## Отмена и обучение

- **Backspace сразу после исправления** на лету возвращает набранное (как у типографики) — и слово попадает в «Мои слова».
- **«Мои слова»** — вкладка «Слова» в настройках: два раздела — «Не переключать раскладку» (как сейчас) и «Не исправлять» (новые). Посмотреть, добавить вручную, удалить.
- Разговорные словечки (ща, чо, спс, хз, норм…) защищены изначально.
- Модель не переучивается: она получает запрет трогать «Мои слова».

## Порядок на клавише (на лету)

Свитчер раскладки → исправлятор опечаток → типографика. Если свитчер исправил слово — опечатки и типографика на этом нажатии молчат. Если исправлены опечатки — длина слова изменилась, память свитчера сбрасывается (как у «…»).

## Где не работает

- Опечатки на лету — там же, где молчит типографика на лету (вкладка «Исключения», раздел переименовывается в «Типографика и опечатки на лету»), плюс поля пароля, e-mail, телефона, ссылок.
- По сочетанию — везде, кроме полей пароля.

## Автозамена macOS

Встроенная автозамена macOS включена по умолчанию и спорит со свитчером (и ставит заглавные, где человек писал строчные). **Свитчер её не выключает сам** — это системная настройка (как с индикатором раскладки). Вместо этого:
- на вкладке «Опечатки» — предупреждение «Автозамена macOS тоже включена…», если она включена (читаем `NSAutomaticSpellingCorrectionEnabled` в общих настройках; нет ключа — значит, включена), и кнопка «Открыть настройки клавиатуры»;
- на финальном шаге онбординга — короткая строка с тем же советом;
- в справке и PDF — путь: Клавиатура → Ввод текста → Изменить… → «Исправлять ошибки автоматически» и «Писать слова с прописной буквы автоматически».

## Настройки — вкладка «Опечатки» (новая)

- «Исправлять опечатки на лету» — вкл/выкл.
- «Запятые по сочетанию» — блок модели: название, размер, статус, «Скачать» / «Удалить».
- «Заглавная буква и точка в конце» — вкл/выкл (только для модели).
- Подсказка: что исправляется («првет → привет», «приввет → привет», «привте → привет», «пожалуста → пожалуйста») и что нет («фигма», «ща», «хз» остаются).

## Проверка

- Автотесты исправлятора: наборы из эксперимента (промахи, редкие слова, контроль сленга и жаргона) с порогами — промахи ≥ 80% верно, ошибочных исправлений ≤ 1%, контроль — 0 тронуто.
- Автотесты фильтра модели на ответах SAGE из эксперимента (без запуска модели): «хз» → «хочу» отброшено, запятые приняты, «15. 00» отброшено.
- Ручная проверка с учеником: опечатки на лету в TextEdit, Telegram, Chrome; отмена Backspace и «Мои слова»; двойной правый Shift с моделью и без; скачивание и удаление модели.
