# Vallo Switcher — передача контекста (для новой сессии)

Обновлено: 2026-11-02. Читать первым, затем `README.md` и спеки в `docs/superpowers/specs/`.

## Кто и как работаем

- Автор — продуктовый дизайнер, код не пишет. **Код пишет и собирает ассистент**, автор проверяет вживую и решает, как должно работать.
- Правило 0: не уверен, что понял, — переспросить. Не своевольничать: дизайн и решения — автора.
- Большие вещи: брейншторм (вопросы по одному) → спека → план → выполнение (TDD) → ручная проверка с автором → финальное ревью свежим агентом → DMG.
- Коммиты — без `Co-Authored-By`. Пушим в `main` (git@github.com:madvito-collab/vallo_switcher.git; 2026-11-02 автор решил открыть его — свитчер бесплатный, лицензия MIT, автор Shmelev Vitaliy; автор не хочет светить телегу — t.me/madvito только в «О программе», не в README/LICENSE). Метки версий: `v0.2` … `v0.6`.
- Тексты интерфейса — **на «вы»** (решение автора по редактуре ChatGPT), через нашу же типографику (`Typographer.format`, неразрывные пробелы).

## Что это

macOS-приложение в строке меню (Swift, SwiftPM, macOS 14+): исправляет раскладку RU↔EN, опечатки, типографику, запятые (модель). Офлайн; сеть — скачивание модели запятых по кнопке и раз в день проверка обновлений (Sparkle).

## Где что лежит

- `Sources/ValloCore/` — вся логика без системных API, покрыта тестами (`swift test`, ~146 тестов, ~3 с):
  `Engine` (раскладка, откат, короткие слова, сленг), `Judge`, `Lexicon`, `Converter`, `Typographer` + `LiveTypographer` (типографика и опечатки на лету, отмена Backspace), `TypoCorrector` (опечатки), `CommaFilter` (фильтр ответа модели), `Hotkey` (сочетания).
- `Sources/ValloSwitcher/` — приложение: `KeyboardTap` (перехват, конвейер: свитчер → опечатки → типографика; правый Shift → опечатки → модель → типографика), `CommaModel` (ONNX Runtime + токенизатор), `CommaService` (запятые, таймауты, защита от вставки не туда), `ModelStore` (скачивание модели), `SettingsView` (вкладки: Основное, Исключения, Типографика, Сочетания, Опечатки, Слова), `StatusMenu` (меню как у Wi-Fi, свой тумблер `PillSwitch`), `OnboardingView`, `ContextGuard`, `SelectionReader`, `EventPoster`.
- `Data/wordlists/`: `ru.txt`/`en.txt` (субтитры, свитчер), `ru-typos.txt` (субтитры + Википедия, исправлятор; собирается `scripts/build-typo-dictionary.py`).
- Модель запятых: релиз `models-1` в публичном `madvito-collab/vallo-models`, `sage-fredt5-95m.zip` (228 МБ, SHA-256 в `Data/models/README.md`). На Маке: `~/Library/Application Support/Vallo Switcher/Models/sage-fredt5-95m`.
- Документы: спеки и планы `docs/superpowers/`, справка `Support/Help.html`, PDF-инструкция `Support/Guide/guide.html` → `scripts/render-guide.sh`, картинки автора `Support/Guide/step*.png`.

## Сборка

```bash
swift test
scripts/install.sh      # собрать, подписать (Apple Development), поставить в /Applications
scripts/package.sh      # build/Vallo-Switcher-<версия>.dmg (с PDF)
scripts/release.sh      # выпуск для автообновления: DMG + подпись Sparkle + запись в appcast.xml, печатает команду выпуска
```

**Выпуск новой версии (автообновление, с 0.6).** Поднять `CFBundleShortVersionString` и `CFBundleVersion` (число, строго растёт) в `Support/Info.plist`, написать «что нового» в `Support/Releases/<версия>.html` (HTML-кусок, по-русски, на «вы»), запустить `scripts/release.sh`. Он печатает одну строку для автора: коммит → метка → пуш метки → `gh release create` (DMG в GitHub Releases) → пуш main (appcast.xml попадает на main ПОСЛЕ DMG, чтобы свитчеры не увидели версию без файла). Свитчеры читают `https://raw.githubusercontent.com/madvito-collab/vallo_switcher/main/appcast.xml` — работает только пока репозиторий открытый. Ключ подписи обновлений (EdDSA) — в «Связке ключей» этого Мака, публичная половина — `SUPublicEDKey` в Info.plist; без ключа выпустить обновление нельзя (копия — у автора в менеджере паролей, экспорт `build/sparkle/bin/generate_keys -x файл`). Инструменты Sparkle скачиваются в `build/sparkle` сами. `build-app.sh` кладёт `Sparkle.framework` в `Contents/Frameworks` (без XPC-сервисов — песочницы нет) и подписывает изнутри наружу.

Подпись — бесплатный сертификат автора; без нотаризации (российский Apple ID не регистрирует Developer ID) — тестеры жмут «Всё равно открыть» или `xattr`. `build-app.sh` через `vtool` ставит SDK 27 в бинарник (иначе нет Liquid Glass). Проверка: `xcrun vtool -show-build "/Applications/Vallo Switcher.app/Contents/MacOS/ValloSwitcher"` — должно быть `sdk 27.x`, не `sdk n/a` (2026-11-02 так и сломалось: `xcrun --show-sdk-version` без `--sdk macosx` отдал пустоту, приложение потеряло Liquid Glass, окно настроек — подгонку высоты; теперь скрипт на пустой версии падает).

**Отложенные мелочи (из ревью):**
- двойное нажатие модификатора отслеживается переключением состояния (можно на побитовые флаги сторон);
- два экземпляра, запущенные в одну секунду, могут закрыть друг друга; `--onboarding` не работает при уже запущенном;
- закрытие онбординга крестиком не останавливает таймер;
- «вакансии» (60-е тысячное место) и замены буквы на букву («ткрул» → «ткнул», «виже» → «вижу») сознательно не исправляются; можно разрешить модели правку окончаний несловарных слов;
- Backspace сразу после пробела запоминает слово в «Не исправлять» (как у типографики);
- «с о счета» → «со счёта» (пробел внутри слова) не делается.

**Частые ошибки «как слышится» — встроены (2026-10-30). Слова списка добавлены в русский словарь свитчера (`Lexicon.load`), иначе на «вобщем» он переключал раскладку посреди слова и исправлятор молчал; после починки проверено автором вживую.** 92 варианта в `TypoCorrector.misspellings` (помоему → по-моему, вобщем → в общем, зделать → сделать, извените → извините…): точное совпадение до проверок длины и словаря, регистр сохраняется, «Мои слова» уважаются, отмена Backspace — как у опечаток. Слова, которые пишут нарочно (полюбому, ево, конешно, скушно, щастье), тоже исправляем — решение автора: «кто пишет нарочно — выключит автозамену». Не вошли: сленг (щас, ваще, чё), зависящее от смысла (что бы/чтобы, вначале, типо), ошибки из двух слов (в течении, в кратце).

**Список хотелок автора (2026-10-30, после разбора «Tireo: типограф Бычкова», alexeybychkov.app — это референс-настроение, не спека):**
- **Ёфикатор** — сделан в 0.5 (см. выше).
- **Аббревиатуры заглавными — свитчер не должен переводить в другую раскладку** (просьба автора: иначе пользователи замучаются вносить их в исключения). Проверено на реальных словарях: «ВГСЧ» → «DUC», «ЖКХ» → «:R{», «PDF» → «ЗВА»; СПГ, ЧС, МЧС, НДС, API, KPI и др. не трогаются. **Сделано и проверено автором вживую (2026-10-30):** `Judge.isAbbreviation` — слово целиком из заглавных (2+ буквы) автопереключение не трогает (и во время набора, и на конце слова); двойной левый Shift работает как раньше. Цена: Caps Lock в не той раскладке («VXC» вместо «МЧС») тоже не исправится автоматически — только двойным Shift.
  Плюс **список частых аббревиатур и расширений** `Judge.abbreviations` (согласован с автором; добавлены в словари свитчера в `Lexicon.load`): набранные в чужой раскладке переводятся («зва» → «pdf», «;r[» → «жкх», «ЗВА» → «PDF»); хоть одна заглавная — целиком заглавными («Pdf» → «PDF», «Жкх» → «ЖКХ», и в своей раскладке тоже — на пробеле/знаке, не на Enter). Убраны из-за совпадений со словами в чужой раскладке: cv (см), exe (учу), рф (ha), пфр (gah). Цифровые (mp3, b2b) не берём — цифра для свитчера граница слова.
- **Дыры типографики** (нашли, прогнав его демо-текст через наш `Typographer`): единицы через неразрывный пробел (100 см, 500 г, 30 м²), °C, проценты (47 %, 0,5 %), разряды (1 000 000), сокращения и инициалы (т. д., А. С. Иванов, ул. Ленина, д. 15), пробел после знака препинания (,чем → , чем), № 5, ≤ ≥, «правом ©», Обьем → Объём.
- **Современные слова — сделано (2026-11-02, после 0.5):** `Data/wordlists/ru-modern.txt` (чат, созвон, дедлайн, лайк…, формы в скобках, `WordForms`), знают исправлятор (`TypoCorrector.modernWords`) и свитчер (`Lexicon.load(extra:)`). Автор дописывает слова сам — по мере встречи.
- **Рубль — сделано (2026-11-02):** «850р», «850 руб» → «850 ₽» (правило в `Typographer`, на лету и по правому Shift); «руб.» с точкой не трогаем. Заодно свитчер больше не переводит единицы сразу после числа («850руб» → было «850he,», «5 шт» → «5 in»): `Judge.unitsAfterNumber`.
- **Валюты по правилам языка:** «100$» → «$100» (доллар и евро — перед числом), цифра + R → знак рубля. Символьную панель/кнопку вставки НЕ делаем — у Мака есть своя.
- **Сниппеты (свои автозамены):** префикс `!`, не `;` (на маковской раскладке `;` искать неудобно): «!почта» → email.
- **Случайный Caps Lock:** «пРИВЕТ» → «Привет» автоматически.
- **Последние исправления** — нужно, но где показывать (выпадающее меню или нет) — автор ещё решает.
- **Транслит выделенного** (privet ↔ привет).
- **Автообновление** — сделано в 0.6 (см. выше).
- **Телефоны** — отдельной версией потом; формат — как в SBOL Typograph (см. ниже): 8 (800) 555-55-50, +7 (495) 500-55-50, +7 (4212) 79-40-35. Решение автора: **мобильный — без скобок** (код оператора набирается всегда: +7 921 123-45-67), **городской — со скобками** (код города можно не набирать внутри города: +7 (495) 500-55-50). Значит, различать мобильный и городской по коду.
- **Второй референс — SBOL Typograph** (github.com/DanilovM/SBOLTypograph, Figma/Sketch/JS, правила в README): автор хочет «всё, что он делает». Лицензии в репо нет — берём правила как описание, код и словари не копируем; словарь ёфикатора — из открытого источника с лицензией. Расхождение: SBOL ставит валюту после числа («109 $», русская норма), автор хочет $ и € перед числом (английская) — значит, по языку текста; уточнить.
- НЕ делаем: галочки на каждое правило (всё работает под капотом), плавающую кнопку, camelCase/snake_case и прочие регистры кода. Переводчик — когда-нибудь.

**Идеи на потом (обсуждались):** раскладка на значке в меню (вместо системного индикатора; автор рисует значок), календарь Outlook + Cisco VPN (отдельный проект, предложена отдельная сессия).
