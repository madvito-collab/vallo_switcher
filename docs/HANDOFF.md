# Vallo Switcher — передача контекста (для новой сессии)

Обновлено: 2026-10-30. Читать первым, затем `README.md` и спеки в `docs/superpowers/specs/`.

## Кто и как работаем

- Ученик — продуктовый дизайнер, код не пишет. **Код пишет и собирает ассистент**, ученик проверяет вживую и решает, как должно работать.
- Правило 0: не уверен, что понял, — переспросить. Не своевольничать: дизайн и решения — ученика.
- Большие вещи: брейншторм (вопросы по одному) → спека → план → выполнение (TDD) → ручная проверка с учеником → финальное ревью свежим агентом → DMG.
- Коммиты — без `Co-Authored-By`. Пушим в `main` (git@github.com:madvito-collab/vallo_switcher.git, приватный). Метки версий: `v0.2`, `v0.3`.
- Тексты интерфейса — **на «вы»** (решение ученика по редактуре ChatGPT), через нашу же типографику (`Typographer.format`, неразрывные пробелы).

## Что это

macOS-приложение в строке меню (Swift, SwiftPM, macOS 14+): исправляет раскладку RU↔EN, опечатки, типографику, запятые (модель). Офлайн; сеть — только скачивание модели запятых по кнопке.

## Где что лежит

- `Sources/ValloCore/` — вся логика без системных API, покрыта тестами (`swift test`, ~124 теста, ~3 с):
  `Engine` (раскладка, откат, короткие слова, сленг), `Judge`, `Lexicon`, `Converter`, `Typographer` + `LiveTypographer` (типографика и опечатки на лету, отмена Backspace), `TypoCorrector` (опечатки), `CommaFilter` (фильтр ответа модели), `Hotkey` (сочетания).
- `Sources/ValloSwitcher/` — приложение: `KeyboardTap` (перехват, конвейер: свитчер → опечатки → типографика; правый Shift → опечатки → модель → типографика), `CommaModel` (ONNX Runtime + токенизатор), `CommaService` (запятые, таймауты, защита от вставки не туда), `ModelStore` (скачивание модели), `SettingsView` (вкладки: Основное, Исключения, Типографика, Сочетания, Опечатки, Слова), `StatusMenu` (меню как у Wi-Fi, свой тумблер `PillSwitch`), `OnboardingView`, `ContextGuard`, `SelectionReader`, `EventPoster`.
- `Data/wordlists/`: `ru.txt`/`en.txt` (субтитры, свитчер), `ru-typos.txt` (субтитры + Википедия, исправлятор; собирается `scripts/build-typo-dictionary.py`).
- Модель запятых: релиз `models-1` в публичном `madvito-collab/vallo-models`, `sage-fredt5-95m.zip` (228 МБ, SHA-256 в `Data/models/README.md`). На Маке: `~/Library/Application Support/Vallo Switcher/Models/sage-fredt5-95m`.
- Документы: спеки и планы `docs/superpowers/`, справка `Support/Help.html`, PDF-инструкция `Support/Guide/guide.html` → `scripts/render-guide.sh`, картинки ученика `Support/Guide/step*.png`.

## Сборка

```bash
swift test
scripts/install.sh      # собрать, подписать (Apple Development), поставить в /Applications
scripts/package.sh      # build/Vallo-Switcher-<версия>.dmg (с PDF)
```

Подпись — бесплатный сертификат ученика; без нотаризации (российский Apple ID не регистрирует Developer ID) — тестеры жмут «Всё равно открыть» или `xattr`. `build-app.sh` через `vtool` ставит SDK 27 в бинарник (иначе нет Liquid Glass).

## Состояние на момент передачи

Версия **0.4 собрана** (2026-10-30): `build/Vallo-Switcher-0.4.dmg` (14 МБ) — 0.3 + список частых ошибок «как слышится». Ученик проверил вручную; метка `v0.4` ставится вместе с коммитом. Следующая работа — по выбору ученика (см. отложенное и идеи ниже).

Замечено: SSH к GitHub иногда разово отвечает «Permission denied (publickey)» — повторить команду.

**Отложенные мелочи (из ревью):**
- двойное нажатие модификатора отслеживается переключением состояния (можно на побитовые флаги сторон);
- два экземпляра, запущенные в одну секунду, могут закрыть друг друга; `--onboarding` не работает при уже запущенном;
- закрытие онбординга крестиком не останавливает таймер;
- «вакансии» (60-е тысячное место) и замены буквы на букву («ткрул» → «ткнул», «виже» → «вижу») сознательно не исправляются; можно разрешить модели правку окончаний несловарных слов;
- Backspace сразу после пробела запоминает слово в «Не исправлять» (как у типографики);
- «с о счета» → «со счёта» (пробел внутри слова) не делается.

**Частые ошибки «как слышится» — встроены (2026-10-30). Слова списка добавлены в русский словарь свитчера (`Lexicon.load`), иначе на «вобщем» он переключал раскладку посреди слова и исправлятор молчал; после починки проверено учеником вживую.** 92 варианта в `TypoCorrector.misspellings` (помоему → по-моему, вобщем → в общем, зделать → сделать, извените → извините…): точное совпадение до проверок длины и словаря, регистр сохраняется, «Мои слова» уважаются, отмена Backspace — как у опечаток. Слова, которые пишут нарочно (полюбому, ево, конешно, скушно, щастье), тоже исправляем — решение ученика: «кто пишет нарочно — выключит автозамену». Не вошли: сленг (щас, ваще, чё), зависящее от смысла (что бы/чтобы, вначале, типо), ошибки из двух слов (в течении, в кратце).

**Список хотелок ученика (2026-10-30, после разбора «Tireo: типограф Бычкова», alexeybychkov.app — это референс-настроение, не спека):**
- **Ёфикатор — в базовую версию, точно.** Спека: `docs/superpowers/specs/2026-10-30-yo-design.md` (двойные слова не трогаем никогда; отмена «ё» в «Мои слова» не попадает).
- **Аббревиатуры заглавными — свитчер не должен переводить в другую раскладку** (просьба ученика: иначе пользователи замучаются вносить их в исключения). Проверено на реальных словарях: «ВГСЧ» → «DUC», «ЖКХ» → «:R{», «PDF» → «ЗВА»; СПГ, ЧС, МЧС, НДС, API, KPI и др. не трогаются. **Сделано и проверено учеником вживую (2026-10-30):** `Judge.isAbbreviation` — слово целиком из заглавных (2+ буквы) автопереключение не трогает (и во время набора, и на конце слова); двойной левый Shift работает как раньше. Цена: Caps Lock в не той раскладке («VXC» вместо «МЧС») тоже не исправится автоматически — только двойным Shift.
  Плюс **список частых аббревиатур и расширений** `Judge.abbreviations` (согласован с учеником; добавлены в словари свитчера в `Lexicon.load`): набранные в чужой раскладке переводятся («зва» → «pdf», «;r[» → «жкх», «ЗВА» → «PDF»); хоть одна заглавная — целиком заглавными («Pdf» → «PDF», «Жкх» → «ЖКХ», и в своей раскладке тоже — на пробеле/знаке, не на Enter). Убраны из-за совпадений со словами в чужой раскладке: cv (см), exe (учу), рф (ha), пфр (gah). Цифровые (mp3, b2b) не берём — цифра для свитчера граница слова.
- **Дыры типографики** (нашли, прогнав его демо-текст через наш `Typographer`): единицы через неразрывный пробел (100 см, 500 г, 30 м²), °C, проценты (47 %, 0,5 %), разряды (1 000 000), сокращения и инициалы (т. д., А. С. Иванов, ул. Ленина, д. 15), пробел после знака препинания (,чем → , чем), № 5, ≤ ≥, «правом ©», Обьем → Объём.
- **Валюты по правилам языка:** «100$» → «$100» (доллар и евро — перед числом), цифра + R → знак рубля. Символьную панель/кнопку вставки НЕ делаем — у Мака есть своя.
- **Сниппеты (свои автозамены):** префикс `!`, не `;` (на маковской раскладке `;` искать неудобно): «!почта» → email.
- **Случайный Caps Lock:** «пРИВЕТ» → «Привет» автоматически.
- **Последние исправления** — нужно, но где показывать (выпадающее меню или нет) — ученик ещё решает.
- **Транслит выделенного** (privet ↔ привет).
- **Автообновление** — очень нужно.
- **Телефоны** — отдельной версией потом; формат — как в SBOL Typograph (см. ниже): 8 (800) 555-55-50, +7 (495) 500-55-50, +7 (4212) 79-40-35. Решение ученика: **мобильный — без скобок** (код оператора набирается всегда: +7 921 123-45-67), **городской — со скобками** (код города можно не набирать внутри города: +7 (495) 500-55-50). Значит, различать мобильный и городской по коду.
- **Второй референс — SBOL Typograph** (github.com/DanilovM/SBOLTypograph, Figma/Sketch/JS, правила в README): ученик хочет «всё, что он делает». Лицензии в репо нет — берём правила как описание, код и словари не копируем; словарь ёфикатора — из открытого источника с лицензией. Расхождение: SBOL ставит валюту после числа («109 $», русская норма), ученик хочет $ и € перед числом (английская) — значит, по языку текста; уточнить.
- НЕ делаем: галочки на каждое правило (всё работает под капотом), плавающую кнопку, camelCase/snake_case и прочие регистры кода. Переводчик — когда-нибудь.

**Идеи на потом (обсуждались):** раскладка на значке в меню (вместо системного индикатора; ученик рисует значок), порт на Windows (логика `ValloCore` переносится, системная часть — заново), календарь Outlook + Cisco VPN (отдельный проект, предложена отдельная сессия).
