# Vallo Switcher — передача контекста (для новой сессии)

Обновлено: 2026-10-30. Читать первым, затем `README.md` и спеки в `docs/superpowers/specs/`.

## Кто и как работаем

- Ученик — продуктовый дизайнер, код не пишет. **Код пишет и собирает ассистент**, ученик проверяет вживую и решает, как должно работать.
- Правило 0: не уверен, что понял, — переспросить. Не своевольничать: дизайн и решения — ученика.
- Большие вещи: брейншторм (вопросы по одному) → спека → план → выполнение (TDD) → ручная проверка с учеником → финальное ревью свежим агентом → DMG.
- Коммиты — без `Co-Authored-By`. Пушим в `main` (git@github.com:madvito-collab/vallo_switcher.git, приватный). Метки версий: `v0.2`, `v0.3`.
- Тексты интерфейса — **на «вы»** (решение ученика по редактуре ChatGPT), через нашу же типографику (`Typographer.format`, неразрывные пробелы).

## Что это

macOS-приложение в строке меню (Swift, SwiftPM, macOS 14+): исправляет раскладку RU↔EN, опечатки, типографику, запятые (модель). Офлайн; сеть — только скачивание модели запятых по кнопке.

## Где что лежит

- `Sources/ValloCore/` — вся логика без системных API, покрыта тестами (`swift test`, ~118 тестов, ~3 с):
  `Engine` (раскладка, откат, короткие слова, сленг), `Judge`, `Lexicon`, `Converter`, `Typographer` + `LiveTypographer` (типографика и опечатки на лету, отмена Backspace), `TypoCorrector` (опечатки), `CommaFilter` (фильтр ответа модели), `Hotkey` (сочетания).
- `Sources/ValloSwitcher/` — приложение: `KeyboardTap` (перехват, конвейер: свитчер → опечатки → типографика; правый Shift → опечатки → модель → типографика), `CommaModel` (ONNX Runtime + токенизатор), `CommaService` (запятые, таймауты, защита от вставки не туда), `ModelStore` (скачивание модели), `SettingsView` (вкладки: Основное, Исключения, Типографика, Сочетания, Опечатки, Слова), `StatusMenu` (меню как у Wi-Fi, свой тумблер `PillSwitch`), `OnboardingView`, `ContextGuard`, `SelectionReader`, `EventPoster`.
- `Data/wordlists/`: `ru.txt`/`en.txt` (субтитры, свитчер), `ru-typos.txt` (субтитры + Википедия, исправлятор; собирается `scripts/build-typo-dictionary.py`).
- Модель запятых: релиз `models-1` в публичном `madvito-collab/vallo-models`, `sage-fredt5-95m.zip` (228 МБ, SHA-256 в `Data/models/README.md`). На Маке: `~/Library/Application Support/Vallo Switcher/Models/sage-fredt5-95m`.
- Документы: спеки и планы `docs/superpowers/`, справка `Support/Help.html`, PDF-инструкция `Support/Guide/guide.html` → `scripts/render-guide.sh`, картинки ученика `Support/Guide/step*.png`.

## Сборка

```bash
swift test
scripts/install.sh      # собрать, подписать (Apple Development), поставить в /Applications
scripts/package.sh      # build/Vallo-Switcher-<версия>.dmg (с PDF)
```

Подпись — бесплатный сертификат ученика; без нотаризации (российский Apple ID не регистрирует Developer ID) — тестеры жмут «Всё равно открыть» или `xattr`. `build-app.sh` через `vtool` ставит SDK 27 в бинарник (иначе нет Liquid Glass).

## Состояние на момент передачи

Версия **0.3 выпущена** (2026-10-30): `build/Vallo-Switcher-0.3.dmg` (14,6 МБ), метка `v0.3` на GitHub, ученик проверил вручную. Следующая работа — по выбору ученика (см. отложенное и идеи ниже).

Замечено: SSH к GitHub иногда разово отвечает «Permission denied (publickey)» — повторить команду.

**Отложенные мелочи (из ревью):**
- двойное нажатие модификатора отслеживается переключением состояния (можно на побитовые флаги сторон);
- два экземпляра, запущенные в одну секунду, могут закрыть друг друга; `--onboarding` не работает при уже запущенном;
- закрытие онбординга крестиком не останавливает таймер;
- «вакансии» (60-е тысячное место) и замены буквы на букву («ткрул» → «ткнул», «виже» → «вижу») сознательно не исправляются; можно разрешить модели правку окончаний несловарных слов;
- Backspace сразу после пробела запоминает слово в «Не исправлять» (как у типографики);
- «с о счета» → «со счёта» (пробел внутри слова) не делается.

**Следующая задача (ученик сказал «да», 2026-10-30):** список частых ошибок «как слышится» с точной заменой — то, что исправлятор опечаток сознательно не ловит (две правки, замена буквы). Примеры: помоиму/помойму/помоему → по-моему, вобщем/вообщем → в общем, всмысле → в смысле, какбы → как бы, зделать → сделать, извените → извините, щитаю → считаю. План: собрать 50–100 самых частых, **показать ученику список перед встраиванием**, потом встроить в `TypoCorrector` (точное совпадение, регистр сохраняется, отмена Backspace как у опечаток), тесты.

**Идеи на потом (обсуждались):** раскладка на значке в меню (вместо системного индикатора; ученик рисует значок), порт на Windows (логика `ValloCore` переносится, системная часть — заново), календарь Outlook + Cisco VPN (отдельный проект, предложена отдельная сессия).
