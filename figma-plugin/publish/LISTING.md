# Vallo Typograph — страница в Figma Community

Тексты для формы публикации. Всё на «вы». Неразрывные пробелы Фигма в форме не показывает, поэтому пишем обычными.

## Name

Vallo Typograph

## Tagline

Типографика, опечатки, «ё» и запятые во всех текстах выделенных фреймов — по двойному Shift

## Description

Выделите один или несколько фреймов и нажмите правый Shift дважды. Все текстовые слои внутри будут причёсаны:

• типографика: тире, «ёлочки» и „лапки“, неразрывные пробелы после предлогов и перед частицами, минус, диапазоны, ×, …, ©, ₽;
• опечатки: лишняя, пропущенная или переставленная буква, «помоему» → «по-моему»;
• буква «ё» там, где она нужна;
• запятые: их ставит нейросеть прямо на вашем Маке, без интернета.

Заглавные буквы и точки в конце плагин не трогает никогда: в интерфейсах это решает редполитика.

После работы появится окошко: что и сколько исправлено. Отменить всё разом можно одним ⌘Z. Оформление внутри текста (жирное слово, цвет, ссылка) сохраняется. Меняется только выделенное: экземпляр компонента меняется сам по себе, главный компонент меняется вместе с копиями.

Важно: плагин работает вместе с бесплатным приложением Vallo Switcher для macOS. Сами правила живут в приложении, плагин только передаёт тексты. Скачать: github.com/madvito-collab/vallo_switcher

Запускать плагин вручную не нужно: Vallo Switcher запускает его сам по двойному правому Shift. Можно запустить и из меню плагинов, тогда он сразу причешет выделенное.

Тексты не уходят в интернет: плагин связывается только с приложением на этом же компьютере.

Vallo Switcher — открытый и бесплатный (лицензия MIT). Он ещё переключает раскладку RU↔EN, когда вы забыли её сменить.

Плагин связывается с приложением Vallo Switcher на этом же компьютере (`ws://localhost:48731`): тексты обрабатываются в нём, в интернет ничего не уходит.
