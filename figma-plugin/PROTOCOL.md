# Протокол «свитчер ↔ плагин Vallo для Фигмы»

Один плагин на Мак и Windows: свитчер любой системы поднимает этот же сервер, плагин о системе ничего не знает. Правил типографики в плагине нет.

## Связь

- WebSocket, свитчер — сервер на `127.0.0.1:48731` (только локально).
- Свитчер принимает только рукопожатия без заголовка `Origin` или с `Origin: null` (так приходит окно плагина) — обычная веб-страница подключиться не может.
- Плагин переподключается раз в 2 с, если связи нет (свитчер не запущен или перезапущен).
- Сообщения — JSON-текст, поле `type` обязательно. Смещения в правках — в единицах UTF-16 (как индексы строк JavaScript и C#).

## Сообщения

Плагин → свитчер:

| `type` | поля | когда |
|---|---|---|
| `hello` | `version` (1), `file` (имя файла Фигмы, `figma.root.name`), `fresh` (`true` — первое подключение этого запуска) | после подключения |
| `mode` | `id`; `mode`: `text` (человек редактирует текст) / `empty` (ничего не выделено) / `layers` + `texts: [{id, text}]`, `skipped` (слои без шрифта) | ответ на `press` |
| `done` | `id` | правки записаны |

Свитчер → плагин:

| `type` | поля | когда |
|---|---|---|
| `press` | `id` (растёт) | нажато сочетание, файл спереди |
| `result` | `id`, `edits: [{id, edits: [{start, end, insert}]}]`, `stats: {commas, typos, yo, nbsp, dashes, quotes, other, layers}`, `skipped` | тексты обработаны |

Правки `[start, end)` — по исходному тексту слоя, по возрастанию, не пересекаются; плагин применяет их с конца.

## Порядок

Плагин живёт одно нажатие (в фоне Фигма показывала бы плашку «Running Vallo»). Свитчер на сочетание: плагин файла на связи — шлёт `press`; нет — запускает плагин (⌘/ → «Vallo» → Enter) и шлёт `press` в ответ на `hello` с `fresh: true`. Плагин, запущенный человеком из меню, тоже говорит `fresh: true` и сразу получает работу. После итога плагин закрывается кнопкой «Готово»; при `text`/`empty` — сразу.

`hello` → … → `press` → `mode` → (`layers`: свитчер обрабатывает) → `result` → плагин пишет, показывает итог → `done`.

На `mode: text` свитчер причёсывает выделенный текст как в любой другой программе.
