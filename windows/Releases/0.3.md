- Цвет, набранный в русской раскладке, исправляется: «№аааааа» → «#ffffff», «#1ф2и3с» → «#1a2b3c».
- Обновления надёжнее: свитчер проверяет их, даже когда GitHub ограничивает запросы.
- Рубли, набранные в английской раскладке слитно с числом, исправляются целиком: «850he,» → «850 ₽». Так же «5мин», «2млн».
- Своё сочетание клавиш для перевода раскладки и для исправления текста: «Настройки → Своё сочетание…», например Ctrl+Alt+K.
- Журнал для разбора ошибок: включите «Режим отладки» в «Основном» и нажмите «Открыть журнал». Ваш текст туда не попадает.
